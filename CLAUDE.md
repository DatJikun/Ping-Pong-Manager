# Współpraca przy projekcie

- Właściciel projektu nie programuje. Codex i Claude samodzielnie podejmują decyzje dotyczące kodu, architektury, testów, migracji zapisów i Gita.
- Z właścicielem konsultuj kierunek gry, priorytety, wygląd i UX, zakres funkcji, ryzyko dla danych oraz wyniki testów wykonywanych z perspektywy gracza.
- Nie wymagaj od właściciela wyboru między technicznymi wariantami ani zatwierdzania szczegółów implementacji. Przedstawiaj po polsku rezultat, wpływ na grę i ewentualne ryzyko.
- Eskaluj decyzję techniczną tylko wtedy, gdy istotnie zmienia rozgrywkę, zakres projektu, termin wydania albo bezpieczeństwo zapisów graczy.
