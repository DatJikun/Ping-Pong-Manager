# Player request cadence

## Goal

Make playing-time requests feel caused by neglect rather than generated by a
coin flip every matchday.

## Rules

- No reserve request before matchday four.
- Candidate must be healthy, in strong form, and unused for at least four
  completed rounds.
- A player waits at least six matchdays before asking again.
- The squad waits at least four matchdays between requests from anyone.
- Once eligible, probability scales gently with form and is capped below 40%.
- Every real match participant, including a reserve entering game four, records
  `lastPlayedMatchday`; season rollover resets the season-relative counter.

## Verification

Add deterministic policy/cooldown tests and a match-participation regression,
then run the full suite. Export the policy only as readable simulation data; UI
does not need to duplicate it.
