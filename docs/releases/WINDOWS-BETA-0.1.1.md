# PingPong Manager 0.1.1 beta (20260821)

Przenośne wydanie Windows x64. Rozpakuj ZIP i uruchom
`PingPong-Manager-0.1.1-x64.exe`. Beta jest niepodpisana, więc Windows
SmartScreen może pokazać ostrzeżenie nieznanego wydawcy.

## Co nowego

- pełniejsze tłumaczenia EN/PL, także dla starszych karier;
- opcjonalny, krótki dźwięk kliknięcia w interfejsie;
- szybsze wizualne potwierdzenie kliknięć;
- obsługa klawiaturą najważniejszych zakładek oraz wyborów nowej gry;
- bez zmian w tożsamości aplikacji i zgodności zapisów.
